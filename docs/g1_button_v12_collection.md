# g1_button_v12 采集：把上限从 37.3 抬到 39.5

2026-09-14。上一版结论见 [g1_button_v11_score_ceiling.md](g1_button_v11_score_ceiling.md)，
其中「40 分做不到」那条**已被本文推翻**。

---

## 1. 结论先行：每一项都有实测

| 项 | v6 | v12 | 依据 |
|---|---|---|---|
| 夹爪 | 闭合 2.0 | **张开 −0.8561** | 蓝色 70 → 52.5mm |
| 阻抗刚度 | kp 150 | **kp 300** | 四色均值 −3.8mm，+0.83 分 |
| 瞄准点 | 47mm | **10mm** | 压穿接触柔度 |
| action | 实际到达位姿 | **下达指令** | 最深帧深 42.7mm（旧数据 −0.2mm）|
| 起点 | 标准差 0.000mm | **抖动 8mm / 1.5°** | 实测 2.9/5.7/2.0mm |
| 保持段 | 固定 150 步 | **随机 60~250** | 覆盖整定暂态多相位 |
| 路径 | 内置随机 | **QD 档案** | 幅度约 2 倍 |
| 颜色映射 | 几何最近邻 | **官方名字硬映射** | 消除静默错采 |

**示范上限 37.28 → 39.47**（800 集实采：蓝 9.99 / 黄 9.97 / 绿 9.83 / 红 9.42）。

## 2. 阻抗才是关键，不是几何

停住的位置**不是几何硬墙，是力平衡点**。三个实验依次证明：

```
瞄准点 30 → 10mm（命令深 20mm）   四色均值 65.4 → 60.5mm
kp 150 → 300（力翻倍）            四色均值 69.2 → 65.4mm
两者叠加 + 张开夹爪                四色均值 → 57.8mm，蓝色 53.4mm = 9.98 分
```

单独试任何一项都不够，**三项叠加才越过 55mm**。这是本轮最大的认知修正：
先前把「单项不够」外推成「组合也不够」，因此错误地断言 40 分不可达。

## 3. action 必须记「下达指令」而非「实际到达位姿」

末端是阻抗控制，示范的到达位姿是用更深的指令压出来的。
模型若学「命令到达位姿」，执行时压力不足，必然停在更外面。实测：

```
                最深帧 action x − state x
v6（到达位姿）       −0.2mm      ← 模型学到「命令你已经在的地方」
v12（下达指令）     +42.7mm      ← 模型学到「要往里压多少」
```

首帧（预备位姿）两者相差仅 8.5mm、四元数点积 0.9997 —— **指令与状态同坐标系，数据自洽**。

## 4. 【评测时必须同步设置】

```bash
export G1_OSC_KP=300
```

action 记的是指令，**同一条指令在 kp=150 与 kp=300 下压出的深度不同**。
两侧不一致，模型学到的量在评测时就对不上。`src/controllers/controllers.py`
的 `create_arm_osc_controller` 读这个环境变量，采集与评测共用同一条路径。

## 5. 归一化统计必须重算，不能沿用 v9/v11

```
            action 右手 x 的 q99     右爪通道
v6          0.7886                  1.000（闭合）
v12         0.8973                  0.048（张开）
```

**v12 的指令比 v6 深 109mm。** 沿用旧统计会把动作归一化到远超 +1 而被压扁。
（v11 那次可以沿用，因为它只是 v6 的截断版，分布未变。）

## 6. 试过但无效的自由度（别再走一遍）

| 尝试 | 结果 |
|---|---|
| 机器人前移 100mm | 逐色变化 < 2mm 噪声，**零收益**，已恢复官方位置 |
| 手腕绕接近轴自旋 ±15/±35 | 只影响两指落在哪侧；绿色 −15 有效，红色三个角度都撞 button01 |
| 手腕偏离接近轴 y=45/75、z=45 | **全部更差**（77~152mm），评分点被甩到旁边 |
| 中间开合度 −0.55 / −0.25 / +0.10 | 两头不讨好，38.2~39.0，均不如全开或全闭 |

## 7. 取舍：按下按钮 vs 指标最优

```
闭合夹爪  四色压入 10~36mm   38.48   录像上看得见实打实按下
张开夹爪  蓝黄压入 0.00mm    39.61   蓝色 9.98/10
```

得分曲线顶点在 50mm、压实只给 6 分——曲线本身奖励「靠近但别撞上去」；
但步骤名写的是「完成模拟按压」。**本轮由参赛者选定张开方案**，事实记录于此。

## 8. 复现

```bash
export G1_OSC_KP=300
python auto_collect_windows.py --out <out> --total 800 --chunk 25   --max_buttons 1 --length_weights 1,1,1,1   --extra "--canonical_ratio 1.0 --clock sim            --steps_approach 200 --steps_retract 120 --steps_hold 150            --target_site_dist 0.010 --grip_r_approach -0.8561 --wrist_spin_deg green=-15            --action_from_cmd            --settle_jitter 60,250 --ready_jitter_mm 8 --ready_jitter_deg 1.5            --trajectory_archive button_traj_archive_v2.json"
```

新增的排查开关：`BLOCKER_DIAG=1`（记录停住时的接触对）、`--only_colors`（逐色标定提速 4 倍）。
