# v6 闭环失败诊断:现状、证据与待验证点

本文给协作方(4060ti 采集/评测机)理解当前对 v6 模型"闭环够不到按钮"的分析进展。
**重点:结论分为"已用数据坐实的"和"尚未证实、需要在你那边干净闭环验证的"两类,请勿混用。**

## 1. 一句话现状

v6 开环(喂训练录制帧)预测准、四色都会朝正确按钮驱动;但**闭环够不到**:红/绿停在 ~88–99mm,
蓝/黄停得更远(~130–152mm)且落到**错误按钮**。**至少有两种不同的失败,原因只查清了一部分。**

## 2. 已用数据坐实的(实测)

### 2.1 模型学到了、且四色接地都正常
- 离线开环(80 样本):右手位置误差 **6.8mm** vs 真实位移 45.5mm,相对 **15%**(<20%=学到了);
  语言四色目标散开 82mm(>50mm=读到了颜色)。
- 分色测"模型在训练帧上是否朝正确按钮驱动"(各 90 样本,朝按钮分量 mm):
  红 +3.8 / 绿 +1.9 / **蓝 +5.9(最强)** / 黄 +3.7,横向跑偏都只有 ~3mm。
  → **四色都朝正确按钮驱动,蓝/黄接地不比红/绿差。语言/接地不是病因。**

### 2.2 病因之一(红/绿停短):近按钮"信噪比崩塌"
按"离按钮距离"分层测开环误差(v6,40 集):

| 距按钮 | 预测误差 | 真实位移 | 相对误差 | 朝按钮分量 |
|---|---|---|---|---|
| 260mm+(远) | 6.6mm | 9.2mm | 71% | +9.6mm |
| 180–260 | 6.7 | 7.9 | 85% | +7.6 |
| 130–180 | 5.0 | 4.6 | 108% | +5.4 |
| **90–130(停滞处)** | 5.2 | **4.4** | **116%** | **+2.3** |
| 0–90(接触/保压) | 4.1 | 0.2 | — | −0.7 |

**模型预测精度恒定 ~5mm,但越近按钮示范位移越小(9.2→4.4mm)→ 近按钮信号被噪声淹没
(相对误差 71%→116%)→ 闭环走走停停,停在 ~100mm。** 远处位移 9mm≫噪声,所以果断向前。

推论(实测支撑):**每帧位移越大信噪比越高。** v6(4.4mm/帧)已勉强;更慢的采集会更差,
更快/更果断的最后一段会更好。**混合方案(模型接近 + 脚本果断收尾)实测能到 24mm**——
正说明"果断收尾"绕开了模型的精度短板。直驱验证过运动学够得着(红到 22mm)。

## 3. 尚未证实、需要 4060ti 干净闭环验证的

**病因之二(蓝/黄停更远 130–152mm、且非最近/错误按钮),信噪比解释不了,我没钉死。**

已知线索(间接,非结论):
- 训练帧上模型明明朝蓝/黄驱动得好(2.1)——所以不是接地。
- 之前连**脚本直驱都够不好蓝/黄**(需 35–38° 不同腕姿,黄甚至非最近)——提示**下排按钮
  (蓝 z=0.204 最低、黄)在控制/运动学上更难够**(要往下伸+换腕姿)。
- 训练里蓝/黄能成(QD 弯路径+各色接触腕姿),但**模型在闭环执行"下伸+转腕"的可靠性差**。

**猜想(未证实)**:模型 marginal 的近按钮精度,叠加下排按钮更苛刻的下伸/转腕,
闭环里对蓝/黄崩得更早、方向带偏。

**需要你在 4060ti 干净地跑分色闭环(每色单独 `--prompt`,`--no_camera_prep`),观测:**
1. 蓝/黄的末端**实际漂到哪**(卡在哪个环节:下伸不够?腕姿不对?奔向哪个错误按钮?)。
2. 红/绿是否复现"停 ~90–100mm";蓝/黄是否复现"停 130–152mm/非最近"。
3. 顺带:官方是**单次按 4 钮**,P2 速通惩罚要求**四钮跨度>20s** 才满分(≤20s×0.6)。
   脚本调度四色时用 `--return_move_steps` 把跨度撑过 20s,并**实测一次跨度**。

## 4. 待定的数据策略(等蓝/黄查清再定)

**红/绿和蓝/黄是两种病,补的数据不同**,所以先别急着大规模重采:
- 红/绿(停短):补"果断近按钮收尾"(大位移、高信噪比)。
- 蓝/黄(下伸够不到/带偏):补"下排按钮的下伸接近 + 从偏离态纠回下排正确按钮"的覆盖。

倾向**在 v6 的 800 集底座上做针对性补采**(不是完全重采),但**前提是先把蓝/黄的闭环机理看清**。

## 5. 诚实标注

- 第 2 节是实测坐实的;第 3 节是**未证实的猜想 + 需要验证的点**。
- 我之前一度把"信噪比"当成唯一根因、又一度归因"协变量漂移/接地弱",都被后续数据部分推翻——
  当前最可信的是:红/绿=近按钮信噪比;蓝/黄=下排按钮闭环执行难,机理待你那边干净闭环坐实。
